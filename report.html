Klaviyo — Flash Week 1 in detail

Launched Mon Jul 27
The launch

Four two-arm campaigns went out over email + SMS — roughly 13K messages. Arm A offered $25 off, Arm B 10% off exterior, each with its own code (FLASHA0730 / FLASHB0730) and content verified correct end to end. A separate founders pair went to the 122 held-out founder-call customers. The VIP early-access send was cancelled before launch.

The data layer behind it

Fieldd job history imported onto 11,443 profiles (lifetime value + job count), a 1,978-profile VIP segment built, and every profile stamped with its test arm. August campaign drafts — win-back, insider, sunset — are staged for review.

What's next

Both offer arms were sent under identical conditions, so the A/B test is a clean read — next report will show which offer drove more bookings. The August program (win-back, insider, sunset) is drafted and queued for review.
